Rummy basics: sequence, set and declaration

In a common 13-card rummy format, the player aims to arrange cards into sequences and sets. A sequence uses consecutive cards from the same suit, while a set groups cards of the same rank. A pure sequence is made without a joker substituting for a card. The exact declaration requirements, scoring and penalties depend on the variant. Read the in-app rules before beginning a round and make sure you understand what counts as a valid hand. If the app provides a practice mode or tutorial, use it to learn the interface without pressure.

How game modes can differ

Points Rummy often finishes in a single round, Pool Rummy can continue until a points limit is reached, and Deals Rummy uses a fixed number of deals. A platform may also list tournaments or mini-games, but these are not necessarily governed by standard rummy rules. Check the number of players, turn sequence, scoring method and any conditions before selecting a mode.
